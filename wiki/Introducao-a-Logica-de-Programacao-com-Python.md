# Introdução à Lógica de Programação com Python

## Algoritmo e lógica de programação

Um **algoritmo** é uma sequência finita e ordenada de passos para resolver um problema. **Lógica de programação** é a forma de organizar esses passos para que um computador possa executá-los sem ambiguidades.

Antes de programar, identifique entradas, regras de processamento, possíveis erros e saídas esperadas. Esse raciocínio independe da linguagem.

## Variáveis e tipos de dados

Variáveis associam nomes a valores. Em Python, alguns tipos frequentes são:

```python
nome = "Ana"          # str: texto
idade = 20            # int: número inteiro
altura = 1.68         # float: número decimal
estudante = True      # bool: verdadeiro ou falso
```

Nomes claros tornam o algoritmo mais fácil de entender e manter.

## Operadores

- aritméticos: `+`, `-`, `*`, `/`, `//`, `%` e `**`;
- comparação: `==`, `!=`, `<`, `<=`, `>` e `>=`;
- lógicos: `and`, `or` e `not`.

Uma expressão combina valores e operadores para produzir outro valor, como `media >= 7`.

## Condições

Condições escolhem caminhos diferentes de acordo com uma expressão booleana:

```python
if media >= 7:
    print("Aprovado")
else:
    print("Ainda não aprovado")
```

Veja [Estruturas Condicionais](Estruturas-Condicionais).

## Repetições

Repetições executam um bloco várias vezes. `for` é adequado para percorrer uma sequência; `while` repete enquanto uma condição for verdadeira. Todo `while` deve ter uma forma clara de terminar.

Veja [Estruturas de Repetição](Estruturas-de-Repeticao).

## Funções

Funções agrupam uma responsabilidade reutilizável. Parâmetros recebem dados, `return` devolve o resultado e type hints documentam os tipos esperados.

Veja [Funções em Python](Funcoes-em-Python).

## Por que aprender Python?

Python possui sintaxe legível, biblioteca padrão abrangente e aplicação em automação, desenvolvimento web, dados, inteligência artificial, educação e testes. A legibilidade ajuda iniciantes a concentrar atenção no raciocínio sem eliminar práticas profissionais.
